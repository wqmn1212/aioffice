# 더미 데이터 미리보기

백엔드(Base44) 없이 대시보드 화면을 확인·테스트하기 위한 정적 HTML 미리보기입니다.

## 실행 방법

`preview/index.html` 파일을 브라우저로 열면 끝입니다. (더블클릭 또는 `file://` 경로)
빌드, `npm install`, `base44 dev`, 로그인 모두 필요 없습니다.

로컬 서버로 열고 싶다면 프로젝트 루트에서:

```bash
npx serve .     # 이후 http://localhost:3000/preview/ 접속
```

## 무엇을 테스트할 수 있나요

- **대시보드**: 요약 카드 4종, 업무 캘린더(월 이동 · 날짜 선택 · 일별 업무), 실시간 에이전트 로그
- **목표별 칸반**: 목표별 컬럼, 작업 카드, 결재 대기 카드의 **승인 / 수정 / 반려** 동작
  (승인하면 작업이 완료로 바뀌고 로그가 쌓입니다)
- **에이전트**: 부서별 팀장 1명 + 팀원 3명 카드와 배정된 작업
- **업무 지시창**: 문장을 입력하면 키워드로 부서를 골라 목표 + 작업 + 로그를 만들고 결과 창을 엽니다
- **다이얼로그**: 작업 결과, 회사 설정, 외부 서비스 연동
- **반응형**: 창을 800px 이하로 줄이면 모바일 사이드바(햄버거 메뉴)가 동작합니다

왼쪽 아래 검은색 패널(미리보기 전용 UI)에서 데이터셋을 바꿀 수 있습니다.

| 데이터셋 | 용도 |
| --- | --- |
| 기본 데모 (24건) | 진행 중 · 결재 대기 · 완료 · 취소 등 모든 상태가 섞인 기본 데이터 |
| 빈 워크스페이스 | 목표/작업/로그가 하나도 없을 때의 빈 상태 화면 |
| 대량 데이터 (72건) | 목록·캘린더·칸반이 많은 데이터에서 어떻게 보이는지 확인 |

변경 사항은 메모리에만 저장되므로 새로고침하면 초기 상태로 돌아갑니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 미리보기 진입점 |
| `dummy-data.js` | 더미 데이터. 실제 엔티티(Company / Goal / WorkTask / Approval / AgentLog) 스키마와 같은 필드를 사용합니다 |
| `preview-app.js` | `src/pages/Dashboard.jsx` 와 `src/components/company/*.jsx` 의 DOM·클래스명을 그대로 재현한 순수 JS 버전 |
| `preview.css` | Tailwind preflight와 shadcn Dialog 중 company.css가 전제하는 최소한의 스타일만 재현 |

화면 스타일은 실제 앱과 같은 `src/components/company/company.css` 를 그대로 링크해서 사용합니다.
즉 **CSS를 수정하면 미리보기에도 바로 반영**됩니다.

## 주의

- 컴포넌트 로직 자체는 React가 아닌 재현 코드입니다. `src/` 의 JSX를 고쳤다면 `preview-app.js` 도 함께 맞춰 주세요.
- 아이콘은 `lucide-react` 대신 같은 규격의 인라인 SVG로 그린 근사치입니다.
- 폰트(Pretendard)는 CDN에서 받아옵니다. 오프라인에서는 시스템 폰트로 대체됩니다.
